Базовые эффекты (фильтрация)

Эффект Описание Параметры / применение
Highpass (HPF) Отсекает низкие частоты ниже порога 300–400 Гц — убирает гул, оставляет только речь
Lowpass (LPF) Отсекает высокие частоты выше порога 3–3.4 кГц — убирает «воздух», делает звук узкополосным
Bandpass (BPF) Пропускает только полосу частот 300 Гц – 3 кГц — основной «радийный» фильтр
Notch / Peaking EQ Вырезает или подчёркивает узкую полосу Удаление резонансов, подчёркивание 1–2 кГц для разборчивости

Динамическая обработка

Эффект Описание Параметры / применение
Компрессор Уменьшает динамический диапазон, делает звук плотным Сильная компрессия (ratio 4:1–10:1), быстрая атака — эффект «перегруженного канала»
Лимитер Не даёт превысить порог, защищает от клиппинга На выходе цепочки, после компрессора
Гейт / Экспандер Заглушает тихие сигналы ниже порога Имитация «пропадания» сигнала, шумоподавление
Транзиент-шейпер Усиливает или ослабляет атаку Подчёркивание щелчков squelch и бипов

Искажение и сатурация

Эффект Описание Параметры / применение
Сатурация (ленточная/ламповая) Добавляет гармоники, «теплоту» и лёгкое искажение Лёгкая сатурация для AM-радио, сильная — для walkie-talkie
Дисторшн / Овердрайв Агрессивное искажение сигнала Перегрузка передатчика, «кричащий» голос
Bitcrusher Снижает битность и частоту дискретизации Цифровой треск, «роботизированный» звук
Wavefolder / Clipper Нелинейное искажение формы волны Экстремальные помехи, сбой оборудования

Модуляция и спецэффекты

Эффект Описание Параметры / применение
Ring Modulator Умножает сигнал на несущую частоту Металлический, «инопланетный» призвук, помехи
Frequency Shifter Сдвигает весь спектр по частоте Эффект «уплывающей» настройки
Pitch Shifter Меняет высоту тона Транспонирование вверх для walkie-talkie (тонкий голос)
LFO (на громкость/панораму) Периодически модулирует параметр «Пропадание» сигнала, мерцание канала
Chorus / Flanger Модуляция задержки Лёгкий «плавающий» эффект, имитация нестабильной связи

Шум и помехи

Эффект Описание Параметры / применение
Генератор белого шума Широкополосный шум Фон эфира, статика
Генератор розового шума Шум с наклоном в низкие частоты Более «естественный» фон
Треск (crackle) Короткие импульсные помехи Старая проводка, плохой контакт
Гул (hum) Низкочастотный тон (50/60 Гц) Питание оборудования, наводки
Squelch-щелчок Короткий импульс в начале/конце передачи Обязательный элемент для реалистичности
Морзе / бипы Тональные сигналы Передача данных, телеметрия

Пространственные и временные эффекты

Эффект Описание Параметры / применение
Короткий реверб (room/plate) Небольшое помещение Диспетчерская, кабина, бункер
Дилей (короткий) Эхо-повторы Эффект «эха» в туннеле, отражение от зданий
Filter Sweep (LP/HP) Плавное изменение фильтра Настройка станции, переход между каналами

Структура цепочек обработки

Назначение Цепочка (порядок эффектов)
Базовая рация (walkie-talkie) Pitch Shift вверх → Bandpass (400–3000 Гц) → Компрессор (сильный) → Сатурация → Генератор шума/треска → Squelch-щелчок
AM-радио Highpass (300 Гц) → Lowpass (3 кГц) → Компрессор → Ленточная сатурация → Лёгкий шум
Военная связь Bandpass (300–3400 Гц) → Экстремальная компрессия → Дисторшн → Bitcrusher → Морзе/бипы → Треск
Диспетчерская Bandpass (300–3 кГц) → Компрессор → Короткий реверб (room) → Фоновый шум → Squelch
Сбой/помехи Ring Modulator → Frequency Shifter → LFO на громкость → Bitcrusher → Хаотичный шум
Параллельная обработка Чистый сигнал + обработанный «радийный» сигнал (смешивание на отдельной шине)

Дополнительные приёмы

Приём Описание
Параллельная компрессия Смешивание сильно сжатой копии с оригиналом для плотности без потери атаки
Sidechain Приглушение фона при появлении голоса (автоматическое «освобождение» канала)
Автоматизация фильтра Ручка настройки, «поиск станции»
Layer stacking Несколько слоёв шума и треска для сложной текстуры помех
