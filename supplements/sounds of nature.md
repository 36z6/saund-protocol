Совет по структуре папок (Иерархия)

Сохраняйте это так, чтобы быстро искать по тембру, а не по названию:

Nature_FX / [Частота] / [Тип_атаки]
Например: Nature_FX / HF_High (4-10кГц) / Impulse_Sharp (сюда: цикады, стук дятла, треск льда).
Nature_FX / LF_Low (20-150Гц) / Pad_Drone (сюда: гул торнадо, землетрясение, океанский накат).
